# Esteira

Instaladores do Esteira. Este repositório não tem código — só os arquivos
para baixar, na aba **Releases**.

## Windows

1. Baixe o `Esteira-Setup-<versão>.exe` da versão mais recente.
2. Abra. Se o Windows mostrar "O Windows protegeu o computador", clique em
   **Mais informações** → **Executar assim mesmo**. Isso aparece porque o
   instalador ainda não tem assinatura digital.
3. O Esteira instala sozinho e abre.

## Mac

1. Baixe o `Esteira-<versão>-universal.dmg`.
2. Abra e arraste o Esteira para a pasta Aplicativos.
3. Na primeira vez, o Mac bloqueia: vá em Ajustes do Sistema →
   Privacidade e Segurança → **Abrir Mesmo Assim**.
